# The Binding of Ashaad: Secrets (spoilers)

- **Title codes** (type them on the title screen):
  - `OHIO`: Ohio variants of enemies.
  - `SKIBIDI`: extra Skibidi Julians.
  - `CABC`: start with the CABC Lunch Tray.
  - `GOLDEN`: golden Julians show up much more often.
  - Konami code (↑↑↓↓←→←→BA): start with the Konami Controller.
- **Golden Julian**: 1 in 100 enemies is golden. It is tougher and drops coins.
- **Landry**: beat Landry to unlock him as a playable serpent.
- **CABC Lunch Tray**: secret item. Get it from the CABC code or a 1 in 60 boss drop.
- **Konami Controller**: secret item, Konami code only.
- **Floor 4, CABC Hallways**: College Academy at Broward College. The boss is The Principal. No running.
- **Finley's secret floor**: bomb the cracked wall.
